# Luxury UI Taste

Use to reduce the AI-generated / machine-like feel.

## Luxury UI principles

- Calmer is usually more premium.
- Fewer elements, stronger intention.
- Smaller but sharper text.
- Wider spacing but with rhythm.
- Thinner borders.
- Less glow.
- Controlled contrast.

## HUD / glass UI

- HUD must not look like an admin panel.
- Reduce hard borders.
- Use blur, opacity, soft shadow.
- Display only 2-3 main pieces of information first.
- Use progressive disclosure for details.

## Typography

- Headings must have rhythm.
- Body text must be short.
- Letter spacing must have a purpose.
- Do not center everything if an editorial/cinematic feeling is needed.

## Anti-template checklist

If the UI looks like a template:

- Reduce card grids.
- Create asymmetry.
- Increase scene continuity.
- Add visual silence.
- Hide unnecessary UI chrome.
