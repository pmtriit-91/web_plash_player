# Style Coherence Review — Universal

## Purpose

Review whether the UI matches its intended design identity.

This is not tied to any specific style.
It applies to any product type and visual direction.

## Review Questions

### 1. Intent Match
Does the UI match the product's actual goal?

Examples:
- dashboard should be clear and scannable
- landing page should communicate value and emotion
- developer tool should feel precise and trustworthy
- documentation should feel readable and navigable
- ecommerce should guide decision and conversion
- creative portfolio should express personality

### 2. Style Consistency
Are components visually coherent with each other?

Check:
- spacing
- border radius
- shadows
- typography
- color usage
- density
- icon style
- motion behavior
- interaction states

### 3. Anti-Generic Check
Does it look like a default template or untouched component library?

If yes, improve through:
- hierarchy
- spacing
- custom states
- component composition
- typography rhythm
- interaction clarity

### 4. Anti-Overdesign Check
Does it use effects that hurt usability or project fit?

If yes, reduce:
- unnecessary glow
- excessive blur
- random animation
- decorative noise
- inconsistent visual metaphors

### 5. Library Fit
Is the chosen UI library helping or constraining the intended style?

If constraining:
- override carefully
- compose custom wrappers
- mix styling approaches when appropriate
- keep accessibility and maintainability

## Output

For reviews, provide:
- what works
- what feels off
- what to change first
- what not to change
- risk if overdone
