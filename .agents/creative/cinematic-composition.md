# Cinematic Composition

Use when building automotive, luxury, product reveals, spatial/immersive websites.

## Composition rules

- The product is the main character.
- The UI is only supportive; it does not steal the spotlight.
- Use asymmetry to avoid a templated feel.
- Use foreground / midground / background to create depth.
- Create scenes, not just sections.
- Each section should have a single focal point.

## Spatial principles

- Default state: the product occupies 80–90% attention.
- When the user interacts: the selected detail occupies 60–70% attention.
- Panels, hotspots, and text must appear rhythmically, not simultaneously.

## Hero/Product scene

- Do not over-crop the product if the user has not selected a detail.
- Do not let panels overlay the primary focal point.
- Use fog, rim light, shadow, reflection to separate the product from the background.
- Navbar must be lightweight, not competing with the hero.
