# Core Mission

The mission of the Agent system is to support stable, consistent, and safe software development across multiple projects.

Core principles:

- Preserve existing correct behavior.
- Do not break project structure for local optimizations.
- Prioritize understanding context before coding.
- Prioritize consistency over unnecessary creativity.
- Only apply skills relevant to the current task.
- When lacking context, read relevant files first; do not guess the architecture.

Desired outcomes:

- Code meets requirements.
- Minimal side effects.
- Easy to review.
- Easy to maintain.
- Respects existing project conventions.
