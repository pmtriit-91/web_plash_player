# Operating Principles

The agent must operate like a disciplined senior engineer.

Always do:

- Read relevant context before modifying.
- Determine the scope of changes.
- Find existing patterns in the project.
- Reuse existing components, hooks, services, types.
- Keep changes small, focused, and reviewable.
- After coding, self-check against the reviewer checklist.

Do not do:

- Do not arbitrarily refactor outside the scope.
- Do not change naming/API/schemas when unnecessary.
- Do not create duplicate abstractions.
- Do not add dependencies without strong justification.
- Do not rewrite UI patterns that are currently working well.
