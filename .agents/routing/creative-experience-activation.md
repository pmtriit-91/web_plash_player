# Creative Activation Contract — V9.1.0

Creative-lite is the default for small-to-medium UI tasks.
The full creative pipeline should only be activated when the task genuinely requires cinematic/premium/motion/storytelling elements.

Do not bypass creative quality when the user requests a UI that is tasteful, less robotic, more premium, or more cinematic.

If creative-lite is insufficient to achieve the desired quality, you must escalate to DEEP.

# Creative Experience Activation

Do not enable full creative by default.

## Lite creative
Use `creative/creative-lite.md` for:
- Slightly cramped UI
- Spacing/hierarchy/contrast adjustments
- Polishing a small section
- Reducing the mechanical feel
- Tweaking a small landing page

## Full creative
Only enable full creative when the task requires:
- Cinematic product experience
- Premium landing page
- Motion storytelling
- 3D/WebGL/showroom
- Awwwards/Apple/Tesla/Porsche level quality
- Complete experience redesign for an entire section/page

## Full creative load
Only read the necessary files:
- `creative/creative-direction.md`
- `creative/cinematic-composition.md`
- `creative/motion-grammar.md`
- `creative/interactive-product-storytelling.md`
- Relevant reviewers if needed

Do not read the entire creative folder if the task only requires minor polishing.
