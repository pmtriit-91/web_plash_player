# Creative Experience Loop

Use when the task requires premium UI, a landing page, a cinematic site, motion, or a 3D/product showcase.

## Loop

1. **Taste Orientation**
   - Read the project's design-system/taste-profile if available.
   - Identify the aesthetic target: luxury, cinematic, minimal, enterprise, playful, etc.
   - Identify anti-patterns to avoid.

2. **Scene Planning**
   - Divide the experience into scenes, not just sections.
   - Each scene must have a focal point and a primary emotion.

3. **Interaction Planning**
   - Determine user actions: scroll, hover, click, drag, inspect.
   - Every interaction must have an intentional response.

4. **Implementation**
   - Write modular code.
   - Separate motion from business logic.
   - Avoid excessive performance overhead.

5. **Creative Review**
   - Is there too much UI?
   - Does it feel like a template?
   - Is there meaningless motion?
   - Is the focal point clear?
   - Are there black spaces or scroll interruptions?

6. **Polish**
   - Reduce if excessive.
   - Increase the pacing if it feels too flat.
   - Optimize responsiveness and performance.
