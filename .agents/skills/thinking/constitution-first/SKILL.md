# Constitution First

Use mission evidence before approving a major direction.

## Review

1. Identify the primary user served by the proposal.
2. State the mission outcome it advances.
3. Define the observable success criterion it should improve.
4. Identify any way it moves the product away from its primary purpose.
5. Ask whether removing the proposal would cause meaningful user harm.
6. Check whether an existing capability already solves the need.

Proceed when the proposal has a clear primary user, measurable value, and no
unresolved mission conflict. Otherwise narrow, defer, or reject it and explain
the evidence.
