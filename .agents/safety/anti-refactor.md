# Anti-Refactor Safety

Hard rules:

- Do not refactor unrelated files.
- Do not rename public exports unless necessary.
- Do not make large folder structure changes unless requested.
- Do not replace stable patterns with new patterns just for preference.
- Do not delete code unless you are certain it is no longer used.

If you find old code that is unoptimized but does not affect the task, log it instead of modifying it immediately.
