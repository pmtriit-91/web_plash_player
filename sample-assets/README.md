# Sample Assets & Gunny Server Test Guide

Thư mục chứa tài nguyên mẫu và cấu hình kết nối dành cho Web Flash Player.

## 1. Kết nối Gunny Server (Local hoặc Private Server)
Để kết nối với Server Gunny qua Web Flash Player:
1. Mở tab **Gunny Bridge** trên thanh công cụ bên phải.
2. Nhập IP Game Server (ví dụ: `127.0.0.1` hoặc IP VPS) và Port (mặc định: `9200`).
3. Nhập đường dẫn Resource Server (ví dụ: `http://127.0.0.1/resource/`).
4. Nhấn **"Khởi chạy Client Gunny"**.

## 2. Thử nghiệm File SWF bất kỳ
Bạn có thể:
- Kéo và thả file `.swf` trực tiếp vào khung giữa màn hình.
- Hoặc chọn các Presets mẫu có sẵn (ActionScript 3.0 Benchmark, Retro Arcade).
